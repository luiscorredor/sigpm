CONFIGURACIÓN INICIAL

Conecta tu proyecto Firebase

Registra una aplicación web en Firebase Console y pega aquí los valores de firebaseConfig. No pegues contraseñas privadas ni archivos de cuentas de servicio.

No se ha guardado la configuración.

Crear la primera cuenta

Las cuentas nuevas comienzan con rol empleado; después asignaremos el rol administrador desde Firestore.

Guarda la configuración y habilita Correo electrónico/Contraseña en Authentication.

PASO A PASO

Qué debes hacer en Firebase

1
Registrar aplicación web

Firebase Console → tu proyecto → icono web (</>) → Registrar app.

2
Copiar la configuración

Busca apiKey, authDomain, projectId y appId en firebaseConfig.

3
Activar Authentication

Build → Authentication → Sign-in method → Correo electrónico/Contraseña.

4
Crear Cloud Firestore

Build → Firestore Database → Crear base de datos.

Importante: el inicio de sesión sí usará Firebase. Los registros de negocio todavía están en localStorage; la siguiente etapa será conectar los módulos a Firestore y ajustar reglas por rol.
